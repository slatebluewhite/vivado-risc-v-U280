E462 사전등록 — shape 를 가로지르는 정확성 검사

E461 에서 드러난 구멍: 차분 검사는 같은 shape 의 참조와 비교하므로 DUT 와 참조가 똑같이
틀리는 오류(K 절단)를 못 본다. shape 를 가로질러 비교하면 잡힌다.

논리 C[i][n] 의 위치는 shape 마다 다르다 (width = cols*S, nTiles = N/width):
    p = n / width,  s = (n % width) / cols,  c = n % cols
    C[i][n] = acc(bank s)(row p*M + i)(col c)
세 shape 가 같은 A, B 에서 같은 C 를 내야 한다.

등록하는 예측:
  [1] (M,K,N) = (4,4,64):  세 shape 가 전부 일치한다 (xmismatch = 000).
      근거 — 세 shape 모두 h >= K 라 K 를 온전히 쓴다. E460 에서 각자 correct 였다.
  [2] (M,K,N) = (4,8,64):  S=4 만 어긋난다 (xmismatch 에서 S=4 비트만 1).
      근거 — h=4 < K=8 이라 K 8 행 중 4 행만 쓴다. S=2 는 h=8 = K 라 온전하다.
      이것이 E461 [B] 에서 차분 검사가 못 본 바로 그 오류다.
  [3] 음성 대조 (한 shape 의 B 를 한 칸 밀기): 반드시 어긋난다.

[2] 가 이 실험의 요점이다. 맞으면 `rows/S >= K` 가 정확성 제약이라는 주장이 처음으로
증명되고, 동시에 새 검사기가 옛 검사기의 사각지대를 실제로 덮는다는 것도 보인다.
