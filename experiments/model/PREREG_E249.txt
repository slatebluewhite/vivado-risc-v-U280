=== E249 사전 등록: a(K)는 대역폭 항인가 ===
E244가 L2 기제를 기각한 뒤 a(K)·b(N)은 기제 없는 실측 곡선으로 남았다.
하드웨어 축으로 흔들면 갈린다: E194가 시스템 버스를 128->256비트로 넓혀
행렬곱 천장을 15.0 -> 24.04 B/cycle로 올렸다(비 1.60).

가설 H1 (대역폭): a는 대역폭에 반비례 -> a_256 = a_128 x 15.0/24.04 = 0.624배
가설 H0 (아님)  : a는 변하지 않는다

같은 바이너리(corner), 같은 클럭(50MHz), 블록 (4,6), Kc=16, N은 nj가 6의 배수.
연산 루프라인은 동일하므로 η만 보면 된다.

  형상          η(3) H1 예측   H0 예측(128비트 실측)
  [ 256x 576]      1.12          1.20
  [ 768x 576]      1.14          1.22
  [2048x 576]      1.87          2.39      <- 28% 차이, 판정자
  [3072x 576]      2.08          2.73      <- 31% 차이, 판정자
  [2048x2304]      1.87          2.39
  [3072x2304]      2.14          2.82

  η(2) H1 예측: 1.08 / 1.06 / 1.34 / 1.48  (H0: 1.13 / 1.10 / 1.55 / 1.77)

b(N)도 대역폭 항이면 같은 0.624배여야 한다:
  b_256(1152)=0.17  b_256(2304)=0.55   (b_128 = 0.28, 0.88)
  -> [256x2304] η(3) = 1+max(0.12,0.55) = 1.55  (128비트 실측 1.88)

반증: 큰 K에서 η(3)이 2.3~2.7 부근으로 128비트와 같으면 a는 대역폭 항이 아니다.
