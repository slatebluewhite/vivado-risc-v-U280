사전 등록 — E315: 독립 matmul이 **2개**일 때의 배분 규칙 (Llama의 gate+up)
작성 시각: 측정 전. 비트스트림: rocket64b1gem3i8w256f50 (서명 확인 완료).

## 왜 이 자리가 비어 있나

SUMMARY §2-4의 규칙: "matmul 하나를 전 가속기로 쪼갠다. 단, 독립 matmul의 개수가
가속기 수의 배수면 하나씩 맡긴다."

근거는 E238·E279·E280인데 전부 **독립 matmul 3개**(BERT의 QKV)로 쟀다:
  3개 / 3대 -> 하나씩이 16% 이득
  3개 / 2대 -> 하나씩이 21~23% 손해 (두 번째 라운드에 한 대가 혼자 돈다)

Llama 계열 FFN의 gate+up은 **2개**다. 그리고 hidden >= 1536의 권장 구성은
**가속기 2대**다(E291·E306). 즉 규칙이 "배수이므로 하나씩"이라고 답하는 자리인데
그 조합은 측정된 적이 없다.

## 설계

Llama 형태 FFN 앞단: A[128 x 1024], W_gate[1024 x 2816], W_up[1024 x 2816] (서로 다른 가중치).
규칙이 고르는 설정: 블록 (8,4), K·N = 2.88M >= 1.4M -> 청크 4 -> Kc=16 (타일 192, 합법).

네 가지 배분을 같은 이진에서 잰다:
  P1  m=1                              (기준)
  P2  m=2, 하나씩 (gate->가속기0, up->가속기1)
  P3  m=2, 각 matmul을 순차로 J분할
  P4  m=3, 각 matmul을 순차로 J분할
  P5  m=3, 하나씩 + 세 번째는 놀림      (규칙이 금지하는 배분 — 얼마나 나쁜지 잰다)

프로세스 8회, `chrt -f 99`, 스케줄별 최소값. 두 출력 모두 정확성 검사.

## 예측

- m=2에서 **P2 > P3** (하나씩이 J분할보다 빠르다). 2가 2의 배수이므로 규칙의 예측이다.
  QKV 3개/3대에서 16%였으니 비슷한 자릿수를 기대하되, 근거는 "분할 손실이 없다"이므로
  **5% 이상**이면 규칙 확인으로 본다.
- m=3에서 **P4 > P5** (J분할이 하나씩보다 빠르다). 2는 3의 배수가 아니므로.

## 판정

- 두 예측 다 맞으면 규칙의 "배수" 조항이 2에서도 성립 -> 표본 밖 확인.
- m=2에서 P3 >= P2 이면 조항은 3개일 때만 참이었다는 뜻 -> 조항을 3에 한정한다.
- 부수: m=2와 m=3 중 어느 쪽이 절대적으로 빠른지도 본다. K=1024이므로 E265의
  "K <= 1024에서는 세 번째가 10~14% 값을 한다"가 적용될 자리다.

## 주의

E304의 교훈 — 규칙이 실제로 고르는 설정이 데이터에 있어야 한다. 블록은 (8,4)로 고정하고
청크도 규칙이 고른 4로 고정한다. 배분만 바꾼다.
