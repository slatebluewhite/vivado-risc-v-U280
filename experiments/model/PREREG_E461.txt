E461 사전등록 — shape_select 규칙의 경계

규칙:  S* = max { S : rows/S >= max(K,4)  and  cols*S <= N }
두 절이 있다. 각각이 실제로 옳은지 따로 시험한다. 16x16, maxSeg=4.

[A] (M,K,N) = (4, 4, 16)  — N 이 좁다. 규칙은 cols*S <= N 절 때문에 S=1 을 고른다.
    **예측: 규칙이 틀린다.** S=4 가 여전히 더 빠를 것이다.
    근거 — S=4 는 pass 하나를 total_rows=4 로 돌고 S=1 은 total_rows=16 으로 돈다.
    남는 열은 시간이 아니라 accumulator 자리를 낭비할 뿐이다.
    이 예측이 맞으면 `cols*S <= N` 은 **시간 기준이 아니라 자원 기준**이므로 규칙에서
    빼거나 뜻을 바꿔 적어야 한다.

[B] (M,K,N) = (4, 8, 64)  — K 가 8. 규칙은 rows/S >= K 절 때문에 S=2 를 고른다.
    **예측: S=4 는 정확성 자체가 깨진다** (mismatch=1). h=4 < K=8 인데 이 하네스는
    K 를 쪼개지 않으므로 D 의 절반만 실린다. 즉 이 절은 성능 기준이 아니라 정확성 제약이다.
    S=2 와 S=1 은 통과하고 S=2 가 더 빠를 것이다.

[C] (M,K,N) = (4, 4, 64)  — E460 재현. 104 / 48 / 32 가 그대로 나와야 한다 (회귀 확인).
