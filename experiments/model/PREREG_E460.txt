E460 사전등록 — 같은 (M,K,N) 을 세 shape 로: MLIR 규칙의 첫 실측 근거

문제: M=4, K=4, N=64.  하드웨어 16x16, maxSeg=4.
각 shape 는 width = cols*S 만큼씩 N 을 덮으므로 nTiles = 64/width 번 pass 한다.

  S=1 (16x16): h=16, width=16, nTiles=4,  total_rows = max(M,h,4) = 16
  S=2 ( 8x32): h= 8, width=32, nTiles=2,  total_rows = 8
  S=4 ( 4x64): h= 4, width=64, nTiles=1,  total_rows = 4

세 shape 모두 총 MAC = 4*4*64 = 1024 로 같다.

등록하는 예측:
  1. 정확성: 세 shape 모두 mismatch=0, 모든 segment 가 0 이 아님. 음성대조 2종 발화.
  2. 순서: S=4 < S=2 < S=1 (사이클). shape_select.py 규칙이 고르는 S=4 가 가장 빠르다.
  3. 크기: S=1 대비 S=4 가 2배 이상 빠르다.
     근거 — pass 당 비용은 대략 (total_rows + 고정오버헤드) 이고 pass 수가 4:2:1 이다.
     고정 오버헤드가 없다면 4*16 : 2*8 : 1*4 = 64:16:4 (16배) 지만, E456 에서 보았듯
     타일 하나짜리 측정은 고정 오버헤드가 지배하므로 훨씬 작게 나올 것이다.

빗나갈 수 있는 곳: 고정 오버헤드가 pass 마다 전부 다시 드는지(그러면 차이가 작아진다),
아니면 파이프라인으로 겹치는지(그러면 커진다). 어느 쪽인지 모르고 재는 것이다.
