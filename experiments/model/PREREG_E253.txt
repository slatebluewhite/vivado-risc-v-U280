=== E253 사전 등록: E252의 특성화가 어느 단계를 움직일지 맞히는가 ===
E252: 열화는 (a) 세 유닛이 함께 돌 때만, (b) 여유가 있던 구간에서만.
      [768x576] +27%, [768x1152] +23%, [768x2304] +2%, [3072x576] 불변, [2048x*] ~불변

E239의 sched 바이너리를 현 상태에서 그대로 다시 돌린다. 단계별 형상:
  QKV      K=768,  N=768  (J분할 m=3)  -> 작은 K, 작은 N  => **+25% 근처로 나빠져야**
  출력     K=768,  N=768               -> 같음            => **+25% 근처**
  FFN1     K=768,  N=3072              -> 큰 N (안정 구간) => **+2% 이내**
  FFN2     K=3072, N=768               -> 큰 K (안정 구간) => **+2% 이내**
  S1(m=1)  전부 m=1                    -> m=1은 불변      => **±2%**

예측 (E239 실측 -> E253 예측):
  S1 합계   75.412 -> 75~77 ms
  S3 QKV     8.664 -> 10.8   출력 2.694 -> 3.4   FFN1 16.406 -> 16.7   FFN2 21.214 -> 21.6
  S3 합계   48.978 -> **52.5 ms**,  향상 1.54배 -> **1.44배**

반증: FFN1·FFN2가 QKV와 같은 비율로 나빠지면 "여유 구간에서만"이 틀린 것.
      m=1(S1)이 나빠지면 "세 유닛이 함께 돌 때만"이 틀린 것.
