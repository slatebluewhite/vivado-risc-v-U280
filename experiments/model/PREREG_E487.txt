E487 사전등록 — 'from S=2 는 3' 은 shape 의 성질인가 pass 수 때문인가

E486 은 (M,K,N)=(4,4,64) 에서 격자를 채웠다. 거기서 pass 수는 S=1/2/4 = 4/2/1 이고,
비싼 출발 shape 는 **2 pass 짜리(S=2)** 였다. 두 설명이 구분되지 않는다:
  [가설 S] shape 의 성질이다 (S=2 라서)
  [가설 P] 직전 phase 의 pass 수가 2 라서

(M,K,N)=(4,4,32) 로 바꾸면 pass 수가 달라진다:
  S=1: pass 2,  모형 72 사이클
  S=2: pass 1,  모형 40 사이클
  S=4: pass 1,  모형 32 사이클

  이제 2-pass 인 것은 **S=1** 이고 S=2 는 1-pass 다.
  [가설 S] -> 2->1 이 3, 1->2 가 1   (E486 과 같다)
  [가설 P] -> 1->2 가 3, 2->1 이 1   (뒤집힌다)

등록하는 것:
  [1] 두 전환 모두 정확성 통과.
  [2] **가설 P 를 예측한다.** E486 의 기전 후보 중 'config_ex 가 직전 matmul 의 배수를
      기다린다' 가 유일하게 남았는데, 배수 시간은 shape 이름이 아니라 그 phase 가 실제로
      한 일(pass 수)에 달렸을 것이기 때문이다.
      틀리면 shape 자체에 무언가가 있다는 뜻이고, 그때는 h 별 drain 을 봐야 한다.
