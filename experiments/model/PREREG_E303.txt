사전 등록 — E303: 청크 임계(K·N ≈ 1.4 MB)가 가속기 수에 비례하는가
작성 시각: 측정 전. 비트스트림: rocket64b1gem3i8w256f50, 서명 확인 완료.

## 배경

E302에서 청크 목표 규칙이 `K·N >= 1.4 MB -> 4, 아니면 2`로 정리됐다 (50칸, 평균 0.14%).
`K·N`은 B 행렬의 바이트 수이고, 임계를 가속기 셋으로 나누면 467 KB로 L2(512 KB)에 붙는다.
전이 구간 1.0~1.6M을 나누면 333~533 KB로 L2를 가운데 두고 걸친다.

이건 기제 가설이지 결론이 아니다. 이 프로젝트는 L2 설명을 개입 실험으로 이미 한 번
기각당했다(E243 -> E244). 하지만 이번 가설은 검정 가능한 예측을 낸다.

## 가설과 예측

H_L2: 기제는 "가속기당 B 크기 대 L2 용량"이다.
      -> 임계는 m에 **비례**한다.  m=3에서 1.4M이면 m=2에서 1.4 * 2/3 = **0.93M**.
      (m=1은 청크 선택이 아예 무의미하다 — E301에서 −0.0~+0.9%로 측정됨.)

H_indep: 임계는 m과 무관한 도형/트래픽 성질이다.
      -> m=2에서도 임계는 **1.4M** 근처.

두 가설은 K·N이 **0.93M ~ 1.4M** 사이인 칸에서 정반대를 예측한다:
H_L2면 청크 4, H_indep면 청크 2.

## 검정 형상 (M=128, 블록 (4,4)·(4,8), 청크 2·4·8)

판별 구간 (0.93M < K·N < 1.4M):
  [1024x1024] 1.05M   (m=3에서 동률 +1.9% — m=2에서 갈리는지가 핵심)
  [ 768x1536] 1.18M
  [1024x1280] 1.31M   미측정
  [1152x1152] 1.33M   미측정
아래 대조 (< 0.93M, 두 가설 모두 청크 2):
  [ 768x1024] 0.79M   미측정
  [ 896x1024] 0.92M   미측정
위 대조 (> 1.4M, 두 가설 모두 청크 4):
  [1280x1280] 1.64M
  [1024x2048] 2.10M

## 판정 기준 (m=2 시간, 2% 미만은 동률)

- 판별 구간 4형상 x 2블록 = 8칸 중 청크 4가 6칸 이상 승 -> H_L2 채택.
- 청크 2가 6칸 이상 승 -> H_indep 채택.
- 그 사이 -> 둘 다 기각. 임계가 m에 비례하지도 무관하지도 않다는 뜻이므로
  기제 가설을 SUMMARY에서 내리고 "임계는 실측표"로만 남긴다.
- 아래·위 대조가 예측대로 안 나오면 측정 자체를 의심하고 판정을 보류한다.

## 부수 확인

- m=1에서 청크 2와 4의 차이가 2% 안인지 재확인한다 (E301의 재현).
  깨지면 E301의 "청크는 공유할 때만 문다"가 형상 의존이라는 뜻이다.
- m=3 판정이 E302와 일치하는지 (같은 보드·다른 이진의 재현성 확인).
