E525 사전등록 — mode-1 의 '256' 이 절대 시각인가 내용/기하인가, mode-2 의 wrs

[절단 1] 통과 칸 (48,64)@16x16 (K%h==0, B=192)의 명령 시작 시각 T0 만 +100/+200 민다.
  실패가 나타나면 -> 트리거는 절대 시각(T0 부근이 256 을 넘는 것) = 하네스 결함.
  그대로 통과면   -> 트리거는 B 행수/기하 = RTL 쪽 개연성 상승.
[절단 2] mode-2 칸 (12,256)@8x8 의 wrs — 기대 쓰기 64 (nt=32 x ch=2).

[예측] [1] t0Pad 로 **실패가 나타난다** (절대 시각) — 근거는 약하다: 주소는 255 를 안
       넘고 용량도 배제됐으므로 내용 쪽 기전이 안 보이는 반면, 시각 쪽은 T0>256 이
       실패 칸들과 정확히 상관한다. 확신 낮음 — 어느 쪽이든 절단은 성립한다.
       [2] wrs < 64 (쓰기 자체가 안 옴 — 값 전부 0 과 정합).
