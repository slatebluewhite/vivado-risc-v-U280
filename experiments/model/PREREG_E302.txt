사전 등록 — E302: E300 청크 목표 규칙의 `K >= 1536` 조항 표본 밖 검정
작성 시각: 측정 전. 비트스트림: rocket64b1gem3i8w256f50 (1코어 3가속기 256비트 50MHz),
서명 확인 완료 (192³ (4,4) m=3 = 0.658 ms -> 256비트).

## 무엇이 걸려 있나

E300은 청크 목표를 두 조항으로 정했다:

    목표 = 4              (K >= 1536)
    목표 = 2 if N/K <= 2 else 4   (그 외)

E278의 N/K 조항은 미지 형상 여섯 개로 표본 밖 검정을 통과했다.
`K >= 1536` 조항은 **이 프로젝트가 이미 가진 42칸에 맞춘 것**이고 검정된 적이 없다.
두 조항은 `K >= 1536 이면서 N/K <= 2`인 영역에서만 갈린다.

## 왜 (4,4)에서만 검정되는가

스크래치패드 `Kc*(I+J) <= 512`가 청크 2를 불법으로 만들면 두 규칙이 같은 답을 낸다.
청크 2가 합법이려면 `(Ktil/2)*(I+J) <= 512`:

    (8,4) I+J=12 -> Ktil <= 84  -> K <= 1344   (K>=1536과 양립 불가)
    (4,8) I+J=12 -> 동일
    (4,4) I+J=8  -> Ktil <= 128 -> K <= 2048

따라서 판별 가능한 영역은 **(4,4), 1536 <= K <= 2048, N/K <= 2** 뿐이다.
훈련 데이터에서 이 조건에 든 칸은 세 개([1536x768], [1536x1536], [2048x1024])였고
셋 다 청크 4가 최적이었다 — 이 조항은 그 세 점에서 나왔다.

## 검정 형상 (전부 미측정)

A군 (판별. K >= 1536, N/K <= 2):
  [1792x 896]  Ktil=112  N/K=0.5
  [1920x1920]  Ktil=120  N/K=1
  [2048x2048]  Ktil=128  N/K=1
  [1536x3072]  Ktil= 96  N/K=2     <- N/K 조항이 가장 세게 반대하는 자리
B군 (대조. K < 1536, N/K <= 2 -> 두 규칙 모두 청크 2):
  [1280x1280]  Ktil= 80  N/K=1

## 예측 (m=3 시간 기준, (4,4) 블록)

가설 H1 (E300, `K>=1536` 조항이 실재):
  A군 네 형상 전부 **청크 4가 청크 2보다 빠르다**.
  B군은 청크 2가 빠르다.

가설 H0 (E278의 순수 N/K 규칙이 옳고 K 조항은 과적합):
  다섯 형상 **전부 청크 2가 빠르다** (전부 N/K <= 2이므로).

두 가설은 A군에서 정반대를 예측한다. 중간 결과(A군이 갈린다)면 조항은
K가 아니라 다른 축(Ktil, 절대 크기, 강도)의 대리변수라는 뜻이고, 그때는
조항을 SUMMARY에서 내리고 측정표로 돌린다.

## 판정 기준

- A군 4/4에서 청크 4 승리 -> H1 채택, 조항을 "표본 밖 검정 통과"로 승격.
- A군 0/4 -> H0 채택, 조항 철회하고 E278 규칙으로 복귀.
- 그 사이 -> 둘 다 기각. 조항을 조건부로 강등하고 무엇이 갈랐는지 별도 조사.
- 차이가 2% 미만인 칸은 "동률"로 세고 승패에 넣지 않는다 (보드 재현성 하한).

## 부수 확인

- 청크 3과 6도 함께 잰다. E300은 "최적은 2 아니면 4뿐, 6은 4가 불법일 때만"이라고
  했다 — 청크 3이나 6이 이기는 칸이 나오면 그 주장도 표본 밖에서 깨진 것이다.
- (4,8)도 잰다. 판별은 못 하지만 최근접 후퇴가 맞는 답을 고르는지 확인한다.
