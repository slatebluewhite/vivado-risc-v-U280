E440 사전등록 — GEMV(M=1)에서 접기의 이득
등록 시각: 측정 전. 16x16, maxSeg=4, K=64, N=64 고정, M만 바꾼다.

파이프라인 시퀀서를 M < h+1에서도 돌도록 스톨(W = max(M, h+1))을 넣었다.
가설: **접기의 이득은 M이 작을수록 크다.** 가중치 프리로드가 h에 비례하는데
M이 작으면 그것을 숨길 계산이 없기 때문이다. GEMV는 M=1이므로 최대다.

식: cycles = (h+1) + passes*W + (L+2) + 2,  L = h+cols,  W = max(M, h+1)
    passes = (N/(C*S)) * (K/h) = N*K/(R*C) — **모양과 무관하게 16**

예측:
  M=1  (GEMV)   S=1 325   S=2 181   S=4 109   -> 2.98배
  M=16 (Gemmini 기본 타일)  S=1 325   S=2 293   S=4 285   -> 1.14배
  M=64 (큰 배치)            S=1 1077  S=2 1053  S=4 1053  -> 1.02배

주목: M=16에서도 S=1은 W=17로 스톨한다 (16 < h+1 = 17). 즉 **정사각 16x16 배열은
Gemmini의 기본 타일 크기 M=DIM=16에서조차 프리로드를 숨기지 못한다** (E437에서 발견).
접은 모양은 h가 작아 숨긴다. 이것이 M=16에서도 1.14배가 나오는 이유다.

정확성: 세 모양 모두 통과, 음성 대조 둘 다 실패해야 한다.
