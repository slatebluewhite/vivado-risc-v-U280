=== E257 사전 등록: max와 가법을 최대로 가르는 자리 ===
현재 상태 적합값(m=3): a(512)≈0.55, a(2048)=1.36, b(2304)=0.92, b(3456)=1.98

N을 2304~3456으로 훑으면 b가 a(2048)=1.36을 가로지른다. 두 구조의 예측이 갈린다:

  max :  η3(K=512)  = 1 + max(0.55, b(N)) = 1 + b(N)        (N이 크면 b가 지배)
         η3(K=2048) = 1 + max(1.36, b(N))
         -> b가 1.36을 넘는 N부터 **두 행이 같아진다(수렴)**
  가법:  η3(K=512)  = 1 + 0.55 + b(N)
         η3(K=2048) = 1 + 1.36 + b(N)
         -> **두 행의 차이가 0.81로 일정하게 유지된다**

기지값으로 크기를 박는다. [2048x3456] η3 = 2.98 (실측). 여기서 b가 지배한다면 b(3456)=1.98.
  max 예측 : [512x3456] η3 = 1 + 1.98 = **2.98**  (2048 행과 같아야 한다)
  가법 예측: [512x3456] η3 = 1 + 0.55 + 1.98 = **3.53**
  -> 18% 차이. 판정자.

또 [512x2880] η3 = 2.21 (실측)이므로 b(2880) = 1.21 < 1.36.
  max 예측 : [2048x2880] η3 = 1 + 1.36 = **2.36** (평평)
  가법 예측: 1 + 1.36 + 1.21 = **3.57**
  -> 51% 차이. 두 번째 판정자.

측정: K = 512, 2048  x  N = 2304, 2592, 2880, 3168, 3456
(N 전부 96의 배수 -> 꼬리 없음. nj = 24,27,30,33,36 전부 3의 배수 -> m=3 불균형 정확히 1.0)
부수적으로 E256이 지적한 b(N)의 표본 공백(2304~3456)을 메운다.

반증: 두 행의 차이가 N=3456에서도 0.7 이상 유지되면 max는 틀린 것.
