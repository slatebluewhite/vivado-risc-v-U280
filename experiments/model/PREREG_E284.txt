=== E284 사전 등록: 본 적 없는 워크로드에 규칙+모델 전체 적용 ===
hidden=1536, FFN=6144, seq=128.  단계 형상: [1536x1536] x4, [1536x6144], [6144x1536]
루프라인 합계 = 4*23.59 + 94.37 + 94.37 = 283.1 ms

[1] 튜닝 규칙(E278)이 고르는 설정:
  QKV/출력 [1536x1536] N/K=1  -> (8,4) 청크2 = Kc48 -> 576타일 초과 -> **청크4, Kc=24** (288)
  FFN1     [1536x6144] N/K=4 -> **(8,4) 청크4, Kc=24** (288)
  FFN2     [6144x1536] K/N=4 -> 예외: (4,4)·(4,8) 둘 다. Ktil=384
           (4,4) 청크8 Kc=48 (384) / (4,8) 청크12 Kc=32 (384)

[2] 모델(E283)이 예측하는 시간:
  QKV: J분할 3회 32.1 대 하나씩 배치 26.0  -> **하나씩 배치 26.0 ms** (E279)
  출력: 10.7 ms
  FFN1: 51.1 ms
  FFN2: (4,4)청크8 73.3 / (4,8)청크12 80.5  -> **73.3 ms**

  층 합계 예측 = **161.1 ms**,  m=1 예측 300 ms,  향상 **1.86배**

반증: 층 합계 오차가 10%를 넘으면 모델이 새 워크로드로 옮겨가지 않는 것.
주의: K=6144는 모델 유효 범위(512~4096)를 넘는 **외삽**이다. FFN2가 가장 위험하다.
