=== E267 사전 등록: 권장 구성에서 BERT 층 ===
E262 (블록 (8,4), 128비트, 코어 2개):  S1 75.392,  최선 43.840 ms = 1.72배
  단계별: QKV 8.204  출력 2.766  FFN1 11.638  FFN2 21.232

E266의 유효한 버스 비교: 256비트가 K≤1024에서 17~21% 빠르고 K≥2048에서 0.
E266의 n 비교: 코어 1개 = 코어 2개 (평균 1.3%).

BERT 단계별 K:  QKV 768, 출력 768, FFN1 768, FFN2 3072.
따라서 K=768 세 단계(합 22.608 ms)만 ~18% 좋아지고 FFN2는 그대로여야 한다.

예측 (1gem3i8w256f50 = 코어 1개, 256비트, 가속기 3개, 블록 (8,4)):
  S1 (m=1)  : ~75.4 ms   (m=1은 η≈1.06이라 버스 무관)
  QKV       : 8.204 x 0.82 = 6.73
  출력       : 2.766 x 0.82 = 2.27
  FFN1      : 11.638 x 0.82 = 9.54
  FFN2      : 21.232 x 1.00 = 21.23
  최선 합계  : **39.8 ms**,  향상 **1.90배**

반증: 합계가 42 ms를 넘으면(즉 개선이 절반 이하면) 버스 효과가 실제 워크로드로
      옮겨가지 않는 것이고, E266의 권고 정정을 재검토해야 한다.
주의: 코어 1개이므로 첫 실행은 오염된다 — 두 번 돌린다.
