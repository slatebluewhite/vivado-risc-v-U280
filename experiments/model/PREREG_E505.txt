E505 사전등록 — 곱 형태가 다른 (h, H) 쌍에서도 성립하나

E504 의 형태:  이득 = [ceil(K/H)/ceil(K/h)] x [max(M,H)/max(M,h)]
h 와 H 를 일반 기호로 적었지만 **확인한 것은 (h=4, H=16) 한 쌍뿐**이다.

비교가 성립하려면 두 구성의 **논리 열 수가 같아야** 한다 (N 타일 수가 같아야 하므로).
접은 r x c 의 논리 열은 c*S 이므로:
  8x8  S=2 -> 논리 열 16, h=4   vs 16x16 (H=16)   H/h = 4    [E504 에서 확인]
  16x16 S=2 -> 논리 열 32, h=8   vs 32x32 (H=32)   H/h = 4    [새 쌍]
  8x8  S=4 -> 논리 열 32, h=2   vs 32x32 (H=32)   H/h = 16   [극단 쌍, PE 비 16:1]

실측 LUT: 8x8 34,290 / 16x16 128,269 / 32x32 496,724
  -> 면적비 0.267 / 0.258 / **0.069**

[예측]
  [1] 세 쌍 모두 곱 형태가 맞는다 (드레인 여유 ~2 % 안). 이득 범위는 [h/H, H/h].
  [2] (h=2, H=32) 쌍은 극단이라 **무승부만으로도 LUT 당 14.5 배**다 (1/0.069).
      즉 H/h 가 클수록 면적 효율이 좋아진다 — 접기를 깊게 할수록 이득.
  [3] 그런데 그 쌍은 `K <= h = 2` 를 요구하므로 무승부 조건(둘 중 하나)이
      `M <= 2` 로 좁아진다. **깊게 접을수록 조건도 같이 좁아진다** —
      면적 효율과 적용 범위가 맞바꿈이다.

[3] 이 맞으면 이 설계의 최종 형태가 정해진다: 얕게 접어 넓게 쓰거나,
    깊게 접어 좁게 쓰거나 — 그리고 batch-1 decode 는 M<=2 를 만족하므로 후자를 쓸 수 있다.
